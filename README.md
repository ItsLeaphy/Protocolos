# Protocolos

Fichas de treino em HTML de arquivo único, pensadas para GitHub Pages (pasta `docs/`). O repositório reúne quatro protocolos — **Toji**, **Maki**, **Megumi** e **Yoshimura** — selecionados em `docs/index.html`.

## Estado

- **Toji** é o único protocolo em desenvolvimento ativo. Está sendo organizado em três frentes: musculação, facial e mobilidade.
- **Yoshimura** é uma frente nova e independente (`docs/yoshimura/`, módulos ES nativos). Estado: estrutura funcional com dados de demonstração; a identidade visual do Figma ainda não foi aplicada. Ver [docs/YOSHIMURA.md](docs/YOSHIMURA.md).
- **Maki** e **Megumi** estão preservados como estão, sem desenvolvimento.

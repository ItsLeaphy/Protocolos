# Protocolos

Fichas de treino em HTML de arquivo único, pensadas para GitHub Pages (pasta `docs/`). O projeto tem três protocolos — **Toji**, **Maki** e **Megumi** — selecionados em `docs/index.html`.

## Estado

- **Toji** é o único protocolo em desenvolvimento ativo. Está sendo organizado em três frentes: musculação, facial e mobilidade.
- **Maki** e **Megumi** estão preservados como estão, sem desenvolvimento.
